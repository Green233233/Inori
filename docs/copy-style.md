# 祈 的文案风格

这份文档是从现有界面文案里反推出来的写法约定。以后新增或改写任何面向用户的文字（按钮、空态、提示、错误、确认框、通知），都按这份来。

## 一句话概括

像一个人在用第二人称跟你说话：短句、口语、带点自嘲和小情绪；句子末尾常常不要句号，出错也要软着说。

## 七个具体规则

1. **第二人称，直接对用户说。**
   用「你」，不用「用户」「本人」。
   - 好：`写下此刻的心情…`、`这句话只有你能看到`
   - 差：`用户可在此输入内容`

2. **短句为主，一句说一件事。**
   超过 20 个字就拆句，或者删掉修饰。
   - 好：`图片太大了，先加载文字凑合看下吧嘿嘿`
   - 差：`由于当前日记所包含的图片体积超过了渲染进程的处理上限，因此系统已自动降级为纯文本模式显示`

3. **句末通常不加句号。**
   单句提示、按钮下的说明、空态描述都不加。成段的解释（隐私说明、权限说明）可以正常加标点。
   - 好：`今天还没有写下什么`、`从下面挑一个贴纸，按住可以拖动`
   - 好（成段）：`授权与撤回永远由你决定。任何一项撤回都会立刻同步给主人端，且无法被远程恢复。`

4. **出错了也要软：`QAQ` / `qwq` + 一句安抚。**
   技术原因照实写，语气不要冷。
   - `恢复手账失败qwq，重新试试好嘛`
   - `图片插入失败qwq，重新试试好嘛`
   - `切换失败QAQ`、`添加失败QAQ`、`移除失败QAQ`、`刷新失败QAQ`
   - `报备失败了QAQ`
   - 严重不可用时补一句：`为您带来的不便作者滑跪道歉QAQ`
   - 例外：真的会丢数据的错误不要说笑，用完整句 + 明确后果。

5. **允许自嘲和玩笑，但不许卖惨、不许过度卖萌。**
   - 好：`老花了啊喂`、`默认字号，开发者严选，纯人工零天然`、`说实话挺大的`、`很粗哦`
   - 差：连续三个以上 emoji、或者每句都带语气词

6. **具体数值和专有名词不口语化。**
   `15 分钟（最省电哒）`、`25 秒（对小狗手机的续航有很大影响哦）`、`Android 13 及以下`、`SAS`、`E2E` 都照原样写。
   - 好：`已启用 · 名单 1 个应用`
   - 差：`已经启用啦，名单里有一个应用哦`

7. **危险操作保持完整句，不给开玩笑。**
   删除、解绑、核销这类不可撤销的动作，格式是：`确定要删除「${标题}」吗？此操作不可撤销！`
   确认按钮用动词（`删除`/`解除`/`确认领取`），不写 `确定`。

## 常用句式模板

| 场景 | 模板 | 例子 |
| --- | --- | --- |
| 空态 | `还没有 X 呀` / `今天还没有写下什么` | `还没有日记呀`、`还没有添加应用。` |
| 空态补充 | `要不 X 试试` / `点下面的按钮，X` | `要不换个关键词试试。`、`点一下下面的按钮，向小狗端现取一次` |
| 成功 | `X 了哦` / `X 啦` | `规则已保存，到点自动生效哦`、`已将涂鸦导出为图片插入正文了哦` |
| 失败 | `X 失败qwq，Y` | `恢复手账失败qwq，重新试试好嘛` |
| 引导下一步 | `先 X，再 Y` | `如果你手上是绑定码，请先用账号登录，再在「绑定」页填写` |
| 隐私/权限说明 | 完整句，说清「谁决定、能不能撤回」 | `授权与撤回永远由你决定。任何一项撤回都会立刻同步给主人端，且无法被远程恢复。` |
| 提醒 | `到点 X` + 影响 | `到点弹一条通知；规则会同步到对方设备，不会唤醒屏幕或常驻后台。` |

## 称呼

- 角色：`主人端` / `小狗端`（英文代码里是 MASTER / PUPPY，中文界面永远写「小狗」）
- 对方：`对方`、`TA`、或者名字（`Aran` / `小不点`）
- 应用自称：`祈`，不用「本应用」「本软件」

## 标点与符号

- 中文标点用全角：`，。：；！？` 与 `「」`（引号优先用直角引号，不用英文双引号）
- 强调时间/数量用括号补充：`15 分钟（最省电哒）`
- 状态用 `·` 分隔：`已连接 · 小不点`、`已启用 · 名单 1 个应用`
- emoji 只在真正的情绪点用一个，不叠加

## 提交前自检

1. 读出来像不像人说的？会不会像系统通知？
2. 有没有第二人称「你」？
3. 单句提示结尾有没有多余的句号？
4. 失败信息有没有给用户下一步，或者至少一句安抚？
5. 数字、版本、权限名有没有被口语化？
6. 这段如果出现在不可撤销的操作上，语气是不是还太轻松？
