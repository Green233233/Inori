# v0.6.2 UI 核验（baseline-ui / accessibility / motion）

## baseline-ui
- 单一主操作：管控中心 4 个 tile 无主次混排；日记页 FAB 唯一强调色；报备弹层主按钮「提交报备」为唯一实心按钮。
- 层级：`SoftCard` 分组清晰，二级页统一 `TopBar` 返回 + 标题。
- 间距/字号沿用既有 token（未引入新梯度）。

## fixing-accessibility
- 图标按钮均有 `accessibilityLabel`（新建日记、搜索、日记设置、取一次位置、清空记录、报备照片缩略图带序号）。
- 列表项 `desc` 含「标题 + 日期」，读屏可辨识。
- 对比度：主要文本 `onSurface`/`primary` 均满足 AA；红底白字按钮保持既有对比度。

## fixing-motion-performance
- 仅 `opacity` 动画（WebView 淡入 ≤150ms，`useNativeDriver: true`）；无 layout 动画、无 `onScroll` 逐帧 setState。
- 编辑页骨架用静态视图，不参与滚动重绘。
