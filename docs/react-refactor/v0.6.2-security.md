# v0.6.2 安全排查

## 数据与权限
- 端到端加密保持不变：ECDH P-256 → HKDF-SHA256(salt=`qi/pair/<pairId>`) → AES-256-GCM，全在 Kotlin；JS 只见密文。券卡密由服务端 Ed25519 签名（唯一例外，已文档化）。
- 新增 `QiLinkService` 只读 relay 的**明文元数据**（kind等）用于弹通知，不解析业务密文；通知正文由服务端存的密文信封不参与。
- 定位：后台采样写本机 `files/qi/puppy-trail.json`，不单独上传；主人端取点走既有 relay 命令，成功后小狗端本地弹「小狗刚刚查看了你的位置」。
- 受控端始终可撤回：权限撤销走系统设置，`PermissionCenter` 只读展示、不可远程开启。

## 残留风险
- relay 明文 kind 暴露「有指令」这一事实（不含内容），可接受但应写进隐私说明。
- debug 包允许明文 HTTP（`usesCleartextTraffic` 仅 debug）；release 必须 HTTPS。
