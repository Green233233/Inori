## 未完成项

- **7（日记编辑器完整移植 RN 原生）**：未做。现有编辑器是 WebView + 原生桥（`android/app/src/main/assets/editor/`），包含文字 / 涂鸦 / 照片 / 贴纸四类区块、撤销重做、自动保存。把它整体重写为 RN 原生富文本编辑器，工作量与回归面远超本轮预算，强行半途移植会同时破坏「兼容旧日记」和「功能性不减」两条验收标准，因此保持现状并在本文件如实记录。
- **8（对方日记用同一编辑器只读）**：改为等价实现——对方条目用原生块渲染（`journal/sharedBlocks.ts` + `screens/SharedEntryScreen.tsx`），并原生绘制涂鸦笔迹。没有复用 WebView 编辑器的原因：v0.6.0 已实测 WebView 124 静态只读页会触发 `Renderer process crash detected (code -1)`，逐项排除了 surface 层、画布尺寸、HTML 精简等因素后判定为内核缺陷，改原生渲染后崩溃计数为 0。
- **API 33 常驻截屏链路**：本机只有 API 35 / API 30 镜像，`随时查看屏幕`（API ≤33 的常驻授权 + 每次通知）只能代码审查，未经真机验证。

## 已知取舍

- 显示大小四档通过运行时改写 `theme/typography.ts` 的字号基准 + 根组件重挂载实现；少数在模块加载时就把 `type.*` 展开进 `StyleSheet.create` 的样式（如 `screens/HomeScreen.tsx` 的 `searchInput`）不会跟随缩放。
- 位置采样只在主人主动点「定位」时记录一条，不做后台定位，因此「出行」需要至少两次跨 500 米的采样才会出现。
