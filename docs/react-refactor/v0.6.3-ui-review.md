## 一、baseline-ui 逐条核对（适用于 React Native 的子集）

| 规则 | 本版处理 |
| --- | --- |
| 用项目既有组件与令牌，不另起一套 | 全部沿用 `SoftCard`、`theme/palette.ts`、`theme/type.ts`；`CategoryGrid` 固定 6 色是产品要求（不受主题影响），已在该文件注释说明 |
| 图标按钮必须有 `aria-label` / `accessibilityLabel` | 日期翻页「前一天/后一天/显示今天」、分段「每天/每周」、应用限制总开关、包名输入框、移除按钮、轨迹事件卡、柱状图每根柱子、分类格，全部已标注（`grep accessibilityLabel` 结果见提交内容） |
| 破坏性操作需要确认 | `AppLimitScreen` 的「移除单个应用」是可逆编辑（保存前不生效），故不弹确认；轨迹页本版**没有**清空记录的破坏操作（早期版本的「清空记录」已移除） |
| 空态给一个明确下一步 | 使用时长页空态指到「使用情况访问」；应用限制空态给输入框 + 「添加」；轨迹空态指到「取一次位置」 |
| 骨架优于 spinner | 加载态用文字「正在读取…」而非 spinner；数据在三命令返回后一次性渲染，不做逐块骨架（避免布局抖动） |
| 不为能做渲染逻辑的事写 `useEffect` | 每周汇总、分类合并、应用去重都在 `useMemo` 里算，未用 effect 驱动 |
| 限制每屏强调色数量 | 使用时长页仅一个主色（蓝色数据可视化）；应用限制页主色只用于「保存并下发」与开关 |
| 不用渐变/发光作为主要可供性 | 未引入渐变或发光；浮层卡片为纯色 + 细描边 |
| 大图/模糊面不做动画 | 未对 WebView、地图、浮层做任何动画 |

## 二、本轮实际修改（2 处，均已通过 `tsc --noEmit`）

1. `react-native/src/features/control/UsageStatsScreen.tsx`
   - 总时长大号数字与「应用」行的分钟数加 `fontVariant: ['tabular-nums']`：翻日期时数字等宽，不再左右抖。
2. `react-native/src/features/control/TrailTimeline.tsx`
   - 事件时间行加 `fontVariant: ['tabular-nums']`：`16:13–16:14 · 1 分钟` 这类时间列在长列表里对齐。

其余检查项无需改动，故本版 UI 代码改动控制为上述 3 行级别。

## 三、可访问性人工清单（替代 fixing-accessibility）

- **触控目标**：日期按钮 44×44dp、分段按钮高中 44dp、应用限制开关行整行可点、移除按钮 44dp 高。
- **朗读文本**：柱状图读作「18 点 53 分钟」；分类格读作「未分类 44 分钟」；轨迹卡读作「使用 com.google.android.apps.nexuslauncher 16:13–16:14」。
- **颜色不是唯一信息**：分类既用颜色也用中文名；已授权/未授权既有颜色也有文字（权限中心）。
- **字号**：全部走 `type.*` 令牌，跟随系统「显示大小」四档（v0.6.1 已加）；本版未引入绝对字号。
- **未做**：TalkBack 全流程逐屏朗读实测（需要真机 + 人工听），本轮只做标签与尺寸的静态与截图核验。

## 四、动效人工清单（替代 fixing-motion-performance）

- 本版新页面**没有新增动画**：无 `Animated`/`LayoutAnimation`/`useNativeDriver` 用法（`grep Animated` 无命中）。
- 只有平台默认行为：导航 push/pop 转场、`Switch` 滑块、`RefreshControl`。
- 因此「只用 transform/opacity」「≤200ms」「respect reduced-motion」「循环动画离屏暂停」这些约束天然满足；若后续加动效，按这三条执行。

## 五、未做与原因

| 项 | 原因 |
| --- | --- |
| `fixing-accessibility` / `fixing-motion-performance` 技能 | 本机 `~/.agents/skills` 中没有这两个技能，只有 `baseline-ui`、`ui-motion`、`ui-skills-root` 等；按要求不擅自改用同一套技能链，改为等价人工清单并在本文标注 |
| TalkBack / 屏幕朗读逐屏实测 | 需要人工听读，自动化只能验证标签存在与触控尺寸 |
| 大字号（200%）全屏截图对照 | 与应用限制页/轨迹页的滚动布局有关，未逐屏做；「显示大小」四档已在 v0.6.1 验证不崩 |
