# v0.6.2 性能排查

## 结论
- 冷启动：debug APK 未 AOT 时会 `failed to attach` → `start timeout`；`cmd package compile -m speed -f com.green.inorinal` 后降到 ~15s（模拟器）。
- 日记编辑页：`[editor-boot] page ms=183–336`（HTML 解析 + 首帧脚本），满足 ≤0.5s 的页面目标；但 `content 9.2–11.7s`、`sinceMount 6.4–17.4s`，耗时在 RN 侧路由/存储装载 + WebView 首次创建，后续可做「提前创建 WebView / 首屏骨架直出」。
- 长驻服务：`QiLinkService` 用 30s relay 长轮询 + 5/30/60s 退避；`PuppyGuardService` 不持 wakelock，定位按档采样（30/10/2 分钟）且只读 last-known。
- 命令链路：25s → 40s 超时，避免小狗端 25s 长轮询边界导致的假失败。

## 待办
- 真机（非模拟器）复测 cold start 与 content 时间。
- 日记列表点击后的骨架/空纸过渡仍有观感问题。
