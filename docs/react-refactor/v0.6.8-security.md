## 已核对结论

### 1. 公告（`broadcast.py` / 路由）

- 所有 SQL 均为参数化：`INSERT … VALUES (?,?,?)`、`DELETE … WHERE id NOT IN (… LIMIT ?)`、`SELECT … WHERE expires_at > ? ORDER BY id DESC LIMIT 1`，无字符串拼接 → 无注入面。
- 输入校验：`text` 去空白后为空拒绝，`len(text) > MAX_TEXT(200)` 拒绝；`hours` 经 `int()` + `max(1, min(MAX_HOURS=720, hours))` 双重夹取 → 无越界写入、无无限期公告。
- 保留策略：插入后 `DELETE … LIMIT 20`，表不会无限增长。
- 鉴权：`GET /api/v1/broadcast` 需设备鉴权（登录态）；`POST` / `DELETE` 声明 `auth_required=False` 但**函数内**先 `admin.check_session(req.db, req.token)`，失败转 `unauthorized`。设备 token 不能写公告 → 无普通用户越权。

### 2. 截屏存档（`ScreenshotStore.kt` / `ScreenshotGalleryModule.kt`）

- 算法：AES-256-GCM，密钥由 `PairRelayCrypto.pairKey()` 派生（ECDH P-256 + HKDF-SHA256，`salt = "qi/pair/<pairId>"`、`info = "qi/msg/v1"`），与 relay 消息同一把，磁盘不存密钥副本。
- nonce：`cipher.iv` 由 JCE 随机生成并要求 12 字节，不复用；AAD = magic + 长度 + 明文 header，header 被认证，改一个字节即 tag 失败。
- 解绑语义：`pairKey()` 需要本机身份私钥 × 对方公钥，解绑后无法再派生 → 旧文件不可解，符合产品「解绑即失效」。
- 路径注入：`file()` 前置 `require(idPattern.matches(id))`，`idPattern = ^[A-Za-z0-9_-]{8,80}$`；`newId()` 内部生成（`shot-<at>-<8 hex>`）。非法 id 抛 `IllegalArgumentException` → `gallery_bad_id`，不会拼出目录穿越路径。
- 写入：`.tmp` → `fd.sync()` → `renameTo()`，失败清理临时与目标文件；`MAX_KEPT=100` 超出即 prune（含 `.tmp` 与损坏 `.enc`）。
- 读取边界：`MIN_FILE` 下限、magic 比对、`headerLength` 上界 `raw.size - (8+4+12+16)` 校验，均在下标运算前完成。
- 桥接层：`requirePair()` 只接受调用方显式传入的当前配对，**不回退**磁盘上的 `qi.link` 旧上下文；错误信息按类型映射为中文短句，不返回密钥/文件路径。

### 3. 全屏消息（`QiFullscreenMessage.kt`）

- 先判 `Settings.canDrawOverlays()`，无权限直接返回 false；`message.isBlank()` 直接返回。
- 时长 `coerceIn(1_000, 30_000)`，不能长驻；`FLAG_NOT_FOCUSABLE`，不可截获输入。
- 仅 `TYPE_APPLICATION_OVERLAY`，不使用已废弃的系统级窗口类型。

### 4. 应用限制（`AppLimitScreen.tsx` / `AppLimitWatcher.kt` / `AppLimitModule.kt`）

- 包名只做 `getApplicationInfo(pkg, 0)` 查询，失败降级为原包名显示；不拼 shell、不拼路径。
- 匹配逻辑是精确比较 `it.pkg == foreground`，不支持通配符/正则 → 不会因用户输入 `.*` 误封全部应用。
- 列表渲染走 RN `Text`（非 HTML 注入面板），应用名来自 `PackageManager.getApplicationLabel`，属于受信任本机数据。

### 5. 公告文本渲染

- 客户端用 `<Text>{broadcast.text}</Text>`，React Native 无 HTML 解析 → 不构成 XSS。
- 后台 `renderBroadcast()` 用 `box.textContent = …`，不是 `innerHTML` → 管理员输入不会执行脚本。
