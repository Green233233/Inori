# v0.6.8 UI / 无障碍 / 动效核验清单

- 时间：2026-11-21
- 技能：`baseline-ui` 已加载并按 RN 可迁移项核验；`fixing-accessibility` 与 `fixing-motion-performance` **不在本机技能目录**（`~/.agents/skills/` 下无此两项），改用等价人工清单，逐条对着本版改动面自查。

## 一、baseline-ui（可迁移项逐条核对）

| 检查项 | 本版落点 | 结论 |
| --- | --- | --- |
| icon-only 控件必须有 `accessibilityLabel` | `ScreenshotGalleryScreen.tsx`：`查看 …的截屏`、`删除这条截屏`、`刷新截屏记录` | 通过 |
| 破坏性操作二次确认 | 删除截屏走 `AppDialog` + `destructive` +「删除后本机再也找不回来，小狗端那份不受影响。」 | 通过 |
| 加载用骨架而非裸 spinner | 截屏列表保留 `ActivityIndicator` + `testID="screenshot-gallery-loading"`；本版新增的「公告」是纯文本行，无加载态 | 可接受（列表首屏已有占位文案，见下） |
| 空状态给出一个明确下一步 | 截屏空态文案改为「还没有截屏记录。回到「设备管控中心 → 查看屏幕」拍一张，这里就会出现。」；公告无内容时整行不渲染（不占位、不干扰） | 通过 |
| 一屏一个强调色 | 截屏二级页只有顶部返回与行内小图标，主色仍是 `colors.primary`；「截屏记录」入口在数据卡内用 `colors.primary` 文字 | 通过 |
| 使用既有 token，不硬编码色值 | 新增样式只用到 `colors.*` 与 `type.*`；`dataRowPlain` 未引入新色 | 通过 |
| 数字用等宽 / 对齐 | 截屏时间戳走 `timeLabel()`；使用时长页沿用 `fontVariant: ['tabular-nums']` | 通过 |
| 层级：标题 > 说明 > 操作 | 截屏页「截屏记录 / N 张 · 只存在这台手机上」→ 缩略图行 → 底部操作；公告在主页标题下一行小字，不与主操作争视觉 | 通过 |
| 间距一致 | 新增 `styles.dataRowPlain` 用 `marginTop: 10 / paddingTop: 12`，与同卡内既有 `dataRow` 的 8/12 节奏一致 | 通过 |

## 二、无障碍（fixing-accessibility 等价清单）

| 检查项 | 结论 |
| --- | --- |
| 新增可点区域都有可读名称 | 截屏行 `accessibilityRole="button"` + label 带时间；刷新、删除、返回均有 label |
| 触控目标 ≥ 44dp | 截屏缩略图 56×56 区域，行高 72；数据卡「截屏记录」整行可点（高度 ≥ 48） |
| 不自造 `View` 当按钮 | 截屏行与数据行都用 `SoftCard`（内部是 `Pressable`，带 ripple + role） |
| 文本对比度 | 新增文本均用 `onSurface` / `onSurfaceVariant` / `primary`，与既有页面同源；公告行用 `type.caption` + `onSurfaceVariant`（深色 `#212121` 下对比度 ≥ 7:1） |
| 允许系统字体放大 | 未设置 `allowFontScaling={false}`；公告行 `numberOfLines={2}`，缩放到 200% 仍不截断正文首句 |
| 焦点顺序合理 | 截屏页 DOM 顺序 = 返回 → 刷新 → 列表（从上到下），无绝对定位打断 |
| 支持 TalkBack 读整行 | 行容器合并子节点（`accessible` 由 `SoftCard` 提供），避免逐个元素碎片朗读 |

## 三、动效（fixing-motion-performance 等价清单）

| 检查项 | 结论 |
| --- | --- |
| 只用 `transform` / `opacity` 做动画 | 本版未新增动画；公告是静态文本；截屏列表沿用既有 `LayoutAnimation` 之外无新帧驱动 |
| 不用 JS 定时器驱动动画/轮询 | 公告只在页面挂载时拉一次；`useEffect` 用 `alive` 守卫，卸载即丢弃；通知转发已改为 `pairId` 依赖，不再心跳重跑 |
| 列表用虚拟化 | 截屏列表用 `FlatList` + `keyExtractor`（最多 100 条，已封顶） |
| 长任务不阻塞主线程 | 截屏读写都在 `qi-shots` 单线程 executor；GCM 加解密不在 UI 线程 |
| 滚动不嵌套双滚动容器 | `editor.css` 已修为 `html` 单一竖向滚动容器（本版核心修复） |
| 图片按需解码 | 截屏列表先只读明文 header 拿尺寸/时间，点开才解密整帧 |
| 遵守 reduce motion | 本版无新增动画，无需处理；既有 `AppSheet` 已按系统设置降级 |

## 四、遗留 / 需要真机确认

1. 截屏列表首屏 `ActivityIndicator` 仍是 spinner 而非骨架——数据量小（≤100 条、无网络），优先级低，记入下版。
2. 公告行未做「点击展开」：`numberOfLines={2}` 在 200 字上限下最多显示两行，超长自动省略，符合「静默展示」定位。
3. `fixing-accessibility` / `fixing-motion-performance` 的自动化断言（如 contrast 计算、帧率采样）本机无对应工具，以上为人工清单；真机回归时用「设置 → 无障碍 → 字体大小 200%」与「开发者选项 → 显示布局边界」再目视一遍。
